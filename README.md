## Reading this portfolio

- Project READMEs identify individual work, team work and inherited teaching material.
- Compiling, host tests, data replay and physical-system validation are distinct checks.
- Recorded metrics retain their original conditions; unverified components are labelled.
- Public forks preserve the original history and author credits. Private curated
  archives remain private; their existence is not a claim of public reproducibility.

Some earlier history uses `oldprize47` or `sangheon47`. This account is the portfolio
entry point. AI coding tools supported parts of my implementation and experiments;
project responsibility does not imply sole manual authorship of every source line.
