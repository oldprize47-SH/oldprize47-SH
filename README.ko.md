# 박상헌

전자제어공학과 컴퓨터공학을 공부했습니다. 임베디드 소프트웨어, 제어, 로보틱스 분야의 인턴과 신입 직무를 준비하고 있습니다.

## 프로젝트

[RealSense 드론 비전](https://github.com/oldprize47-SH/realsense-drone-vision)에서는 팀 프로젝트의 카메라·비전 부분을 맡았습니다. 헬리패드 이미지 수집과 라벨링, 경량 검출 모델 비교, 임베디드 추론, 추적과 표적 정보 전달을 다뤘습니다. 기체 전체는 공동 작업이며 반복적인 정밀착륙은 입증하지 못했습니다.

[STM32 임베디드 제어](https://github.com/oldprize47-SH/stm32-embedded-controller)는 주변장치 개인 실습과 RC카·자동 분리수거 장치 팀 프로젝트입니다. C로 타이머, PWM, 센서 입력과 직렬 통신을 다뤘습니다.

[모터 시스템 식별](https://github.com/oldprize47-SH/motor-system-identification)은 2인 디지털 제어 프로젝트입니다. 정현파 입력 실험, 응답 분석, MATLAB/Simulink 모델 비교에 참여했습니다. 저장소에 당시 측정 데이터의 그래프와 재실행 결과를 정리했습니다.

[시선 추적 마우스](https://github.com/oldprize47-SH/gaze-mouse-course-project)는 김선우와 함께 만든 웹캠 기반 인터페이스입니다. 시선으로 포인터를 움직이고 눈 깜빡임으로 클릭하도록 구현했습니다. 팀 시연 영상과 당시 평가의 한계를 README에 적었습니다.

알고리즘, 운영체제, 영상처리, AI 및 웹 과제는 [영문 소개](README.md)에 연결했습니다. 이전 저장소 이력에는 `oldprize47`, `sangheon47` 계정이 사용됐습니다. 공동 작업과 수업 제공 코드는 각 저장소에서 구분하고 있으며, 구현과 실험 일부에 AI 코딩 도구를 사용했습니다.
